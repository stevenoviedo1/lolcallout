## 1. Hours alone do not grow the brain

**Finding:** At pro/semi-pro levels, practice *quantity* explains little of in-game performance. Players can log 16,000+ hours over a decade; quantity still correlates weakly with expertise. LoL players themselves report “grind more games” as low-effectiveness training (Abbott et al., 2022; Pluss et al., 2021–2022).

**Implication for coaching**

- Stop rewarding game count; reward **one variable improved**.
- Session design = short intentional blocks + feedback, not marathon ranked.

**LOLCallout behavior**

- One learning objective (LO) per block.
- Post-game: “when did you lose control?” not “queue again.”

## 2. What elite LoL brains actually do better

### Cognitive flexibility (task switching)

Top ~0.17% global LoL players show **smaller task-switch costs** and better interference control than average players with the **same hours played** (Li et al., 2020, *Acta Psychologica*). Skill, not mere exposure, tracks executive control.

Cognitive flexibility also correlates with **rank percentile** in LoL (Valls-Serrano et al., 2022).

**Coach translation**

- “Switch jobs” when the board changes: farm → fight → base → obj.
- Call out **role in this fight** (engage / secondary / peel / poke) — forces set reconfiguration.
- Avoid one script for the whole game (that is inflexible cognition).

### Decision quality & impulse control

Top players show better **impulse control** (fewer false alarms on continuous performance tests) (Li et al., 2020). Decision-making measures relate to in-game farm efficiency (Valls-Serrano et al., 2022).

**Coach translation**

- High-% vs low-% language = trained inhibition.
- Red light on man deficit = “don’t press the button.”
- Comfort with **inaction** is a feature of expert control, not passivity.

### Mental models grow with structured experience

Skill and **mental model matching** (how well your internal model matches the game’s real structure) rise together with experience (Wasserman & Koban, 2019). Blind grinding without reflection builds weak, distorted models.

**Coach translation**

- Always name the **system**: tempo, wave, numbers, vision.
- Feedback loop: concept → apply → review cause/effect.

## 3. Deliberate practice (Ericsson) applied to solo queue

Classic criteria for deliberate practice:

1. **Clear intention** for the session  
2. Task is doable and developmentally useful  
3. **Immediate, actionable feedback**  
4. Multiple attempts  
5. Coach/system designs the next focus  

(Ericsson et al., 1993; Ericsson, 2021)

**Solo queue often violates this:** no intention, delayed/no feedback, ego goals (“I need LP”), no coach.

**LOLCallout as practice engine**

| Criterion | Implementation |
|-----------|----------------|
| Intention | Session LO (deaths, CS, man-advantage only, etc.) |
| Feedback | Live callout + death habit + post-game grade |
| Chunking | One concept per 3-game block |
| Next task | Habits list = next block’s LO |

**3-block process** (We Teach League / BBC practice culture): play a short high-intensity block, then reset mentally / review — prevents narrative spiral and recycle-bin tilt.

## 4. Ecological skill acquisition (constraints & affordances)

Skill = identifying, organizing, and executing solutions **in context** (Williams et al.).  
Ecological dynamics: behavior emerges from **individual × environment × task** constraints (Newell; applied to LoL by Bubna et al., 2023, *Frontiers in Psychology*).

In LoL:

| Constraint | Examples |
|------------|----------|
| Individual | Champ kit, skill ceiling, your role, HP/gold |
| Environment | Enemy comps, fed threats, ally deaths, fog limits (legal data only) |
| Task | Win this game / this objective / this wave |

**Affordances** = “what the board invites you to do” (man advantage = invite fight; 20% HP = invite leave).

**Coach translation**

- Rank options from **this** board (choice engine + brain boost).
- Same event, different affordance by role (jg vs support vs ADC).
- Never invent fog — only legal Live Client affordances.

## 5. Working memory & cognitive load

Working memory is tiny. Expert game sense uses **chunking** and **mental representations** so decisions feel automatic (Ericsson; gamesense pedagogy).

**How to grow game sense without only more hours** (cognitive learning pattern):

1. **Slow down** — one idea (LO)  
2. **Encode** — name it out loud (coach speaks it)  
3. **Retrieve** — review / death pattern  
4. **Apply** — next games under the same LO  
5. **Adapt** — switch LO when stable  

**Coach translation**

- One LO per block; ban tip spam.
- Silence is healthy (protect load mid-fight).
- Death = encode one habit, not five.

## 6. Macro structure = the “brain OS” of League

From structural coaching frameworks (macro wall / tempo / waves / vision):

| Layer | Brain job |
|-------|-----------|
| **Mechanics** | Execute champion actions |
| **Micro** | Trades, spacing, CD tracking |
| **Macro structure** | When/why: tempo, waves, vision, numbers |
| **Meta-cognition** | Review control points; update model |

Climbing past the **macro wall** means upgrading structure and meta-cognition, not only CS and combos.

**Tempo** = initiative (move first).  
**Waves** = geometry (force enemy location/time).  
**Vision** = push → move first → ward → control → more tempo.

## 7. Emotion is a performance system

Esports research ties performance to affective regulation, tilt, fatigue, and flow (Pedraza-Ramirez reviews; sensor/ML workload studies). Structure reduces chaos-feel; chaos-feel feeds tilt.

**Coach translation**

- Permission to fail + subtract egregious only.
- Behind: lose gracefully / mosquito — not “game over” narrative.
- Post-game: control timeline, not self-attack.

## 8. Practical “grow your brain” protocol (player-facing)

### Daily / session

1. Pick **one LO** (e.g. man-advantage only; crash before base).  
2. Play a **3-game block** (or stop after tilt).  
3. After block: answer  
   - When did I lose tempo?  
   - Which wave broke the map?  
   - One habit to subtract next block.  

### Weekly

- One VOD: failed plays only — variables (numbers, HP, CDs, first-in).  
- Switch LO only when the previous is automatic.

### What not to do

- Infinite ranked with no LO.  
- Copying challenger VODs as “this is how gold should play.”  
- Rebuilding your entire champion every loss.

## 11. Expanded brain layers (web-informed, 2025–2026 synthesis)

Additional patterns pulled from coaching sites, macro guides, VOD methodology, and skill-acquisition research:

### Decision checklist (value tradeoffs)
Before forcing a play, answer: **What / Why / Gain / Cost / Worth it?**  
(Common macro coaching pattern — e.g. “five golden questions” style frameworks in Challenger macro content.)

### Highest value on the map
Macro as a repeating puzzle every ~20s: *what is the single most valuable thing I can do right now?*  
Pattern taxonomies group skills into **economy · vision · map movement · fighting · game state** (e.g. MOBA Trainer pattern-map style). Train 1–3 weak patterns, not 50 at once.

### Mental stack (attention order)
Protect working memory with a fixed check order:  
**self HP/gold → numbers → threat → obj clock → win con → wave job → role job**.

### Affordances (ecological skill acquisition)
The board *invites* actions (man advantage → convert; low HP → leave). Coaching names invites instead of one fixed script (Bubna et al., Frontiers 2023 — constraints/affordances in esports).

### VOD protocol
Pick one confusing loss → one question → real mistake behind each death → **1–2 fixes only** → apply next block (summonerschool / RiftRec-style routines).  
Coach seeds these questions automatically from live focus.

### Load modulation
When deaths + numbers + threats + obj clock stack, **cognitive load is high** → shorter safer callouts (inhibition, hold, base). Matches expert impulse control findings.
